# Open methods resources

These source-grounded implementation aids make the methods and evidence boundaries in four canonical works easier to inspect and reuse. They add no study results and do not replace the cited versions of record.

| Resource | Purpose | Canonical source |
|---|---|---|
| [Regulatory document evidence matrix](REGULATORY_DOCUMENT_EVIDENCE_MATRIX.csv) | Separates inspected instruments, manufacturer-reported events, permissible inferences and claims the evidence does not establish. | [10.5281/zenodo.22761782](https://doi.org/10.5281/zenodo.22761782) |
| [PINNACLE-TRAJ cohort-construction specification](PINNACLE_TRAJ_COHORT_CONSTRUCTION_SPEC.md) | Converts baseline, scoring-era, transfer, duplicate and 150–210-day endpoint rules into a deterministic sequence. | [10.5281/zenodo.22761832](https://doi.org/10.5281/zenodo.22761832) |
| [PINNACLE-TRAJ missingness and sensitivity matrix](PINNACLE_TRAJ_MISSINGNESS_SENSITIVITY_MATRIX.csv) | Lists the planned MAR, observed-case, weighting, MNAR and window analyses with their limits. | [10.5281/zenodo.22761832](https://doi.org/10.5281/zenodo.22761832) |
| [PINNACLE-VAL variable dictionary](PINNACLE_VAL_VARIABLE_DICTIONARY.csv) | Defines planned index, comparator, reliability, anchor and status variables without representing targets as achieved samples. | [10.5281/zenodo.19482476](https://doi.org/10.5281/zenodo.19482476); [10.17605/OSF.IO/78WF5](https://doi.org/10.17605/OSF.IO/78WF5) |
| [PINNACLE-VAL analysis decision register](PINNACLE_VAL_ANALYSIS_DECISION_REGISTER.md) | Separates fixed protocol methods from implementation choices that require a timestamped audit trail. | [10.5281/zenodo.19482476](https://doi.org/10.5281/zenodo.19482476); [10.5281/zenodo.19482123](https://doi.org/10.5281/zenodo.19482123) |
| [Participation-review extraction schema](PARTICIPATION_REVIEW_EXTRACTION_SCHEMA.csv) | Supplies a machine-readable header for dual-reviewer extraction of meaningful-change evidence. | [10.5281/zenodo.22827813](https://doi.org/10.5281/zenodo.22827813) |

PINNACLE-VAL is retrospectively registered because some planned analyses had already run. Its planned n=300 and n=60 targets are not achieved samples, and no completed concurrent-validity result is published. The AbilityScore monograph contains preliminary operational evidence. The participation-review protocol contains no completed review findings.
