## Distribution acceptance

Root and all reachable leaf hashes determine changed sitemap graphs. Existing durable submission states win over a newly generated pending job. Complete stable publisher content fingerprints, resource reading/content fingerprints and approved R2 identities/ETags determine notification identity independently of sitemap bytes. A real body-only edit may notify the same URL again; an unchanged retry cannot. IndexNow 200/202 means submitted, not indexed. Source retirement must be a two-pass verified source withdrawal plus current 404/410 and prior eligible-page proof. Unknown failures are never inferred retirements.

Google uses supported sitemap PUT/readback and requires zero returned errors plus a new completed download before marking download verified. Bing uses JSON REST SubmitFeed/GetFeeds and a new Success crawl. Retry-After is honored; three submission attempts are bounded independently of later processing readback. Missing supported authentication remains pending. No generic page Indexing API, retired ping endpoint, invented Google/Bing ingestion or forced unchanged submission is present.
