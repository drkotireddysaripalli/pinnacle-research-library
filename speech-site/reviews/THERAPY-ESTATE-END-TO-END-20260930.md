## Operational and evidence boundaries

The owner-confirmed header counts and the dated Speech assessment offer were not treated as unverified merely because this review focused on layout and user flow. The 62 published centre listings are not evidence that every listed centre has current staff, appointment capacity or the particular therapy. The receiving team owns calls and enrolment follow-through. Real connected calls, suitable-service conversations, booked/attended visits and admissions must be measured separately from click events; no page can establish them by itself.

The next efficient release should resolve the anchor and speech-offer continuity issues together, then recheck the one shared shell, affected pages, API entry behaviour and protected routes. The legacy URL decision needs actual Search Console/backlink evidence first. Image generation and full-page revalidation should be repeated only if that batch changes a visual, a source claim or the shared layout.
