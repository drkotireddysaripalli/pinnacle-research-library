## Standard for every new page

1. Freeze the audience job, exact URL, source facts, accepted assets and one primary action: **9100 181 181**, with selected-centre enquiry where useful.
2. Write a distinct life-first narrative: recognisable family need → everyday possibility → relevant therapy/module/place → practical next step → source-linked confidence → call/visit/enquiry. Explain how work at therapy, home and school connects to growing independence and participation.
3. Create needed complete branded posters directly through the built-in ChatGPT image tool. Use the official emblem/lockup, luminous Pinnacle palette, clear typography, age-relevant illustrative scenes and truthful quiet evidence panels. Real centre images stay branch-matched; no API-key route or pasted-text substitute.
4. Implement in existing shared layout/components and typed content. Keep header/footer edits common. Give the page its own useful headings, icons, responsive images, FAQs, visible evidence links, exact canonical, social card, source exports and appropriate visible-content schema.
5. One consolidated read-only narrative/source/technical review, one correction pass, production build and focused meaningful checks. Test phone/tablet/desktop, disclosure/keyboard, source/enquiry/phone/share/citation and protected routes; do not repeat unchanged whole-site checks.
6. Push source before full-union deployment. Preserve bindings and all unrelated triggers; never use a narrowing `--route` override. Verify public HTML/assets/aliases/exports and keep rollback evidence.
7. Notify IndexNow once only for materially new/changed canonicals. Update the release receipt, page/centre ledger and source graph. Then observe search/citation/call outcomes without inferring them from publication.
