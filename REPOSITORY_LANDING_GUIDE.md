# Repository Landing Guide

Use this page to reach the most relevant public research resource without treating repository metadata as a new study, result, citation or endorsement.

## Start by task

### Understand the seven-work portfolio

- Read the [research portfolio overview](RESEARCH_PORTFOLIO_OVERVIEW.md) for one source-linked table of questions, study types and limits.
- Open the [public research briefing](Pinnacle_Public_Research_Briefing.md) for a fuller reader narrative and reusable RCI figures.

### Cite a work

- Use [canonical CSL citations](CANONICAL_CITATIONS_CSL.json) or the [citation and version guide](CITATION_AND_VERSION_GUIDE.md).
- Cite the original Zenodo DOI for the individual work. The repository-level [CITATION.cff](CITATION.cff) identifies the library and does not replace work-level citations.

### Reconcile a researcher profile

- Start with the [scholarly profile field map](SCHOLARLY_PROFILE_FIELD_MAP.csv) and [reconciliation guide](SCHOLARLY_PROFILE_RECONCILIATION_GUIDE.md).
- Preserve Bharath Healthcare Laboratories Private Limited as the professional affiliation. Record Indian School of Business only as completed online executive education. Keep Koti Reddy Saripalli and Sreeja Reddy Saripalli distinct.

### Review methods or reproducibility

- Use the [methods resource index](METHODS_RESOURCE_INDEX.md) for protocol implementation aids.
- Use the [RCI data README](RCI_DATA_README.md) for the reproducible register analysis, its source checksum, data dictionary and limitations.
- Planned analysis files, variable dictionaries and reporting templates do not indicate that recruitment, analyses or results are complete.

### Audit versions and evidence status

- Use the [research metadata index](RESEARCH_METADATA_INDEX.md), [work status matrix](CANONICAL_WORK_STATUS_MATRIX.csv), [relationship map](CANONICAL_WORK_RELATIONSHIP_MAP.csv) and [DOI resolution manifest](CANONICAL_DOI_RESOLUTION_MANIFEST.csv).
- Use the [open-science changelog](OPEN_SCIENCE_CHANGELOG.md) and [release manifest](PORTFOLIO_RELEASE_MANIFEST.csv) to trace repository resource releases.

### Reuse or correct metadata

- Follow the [researcher summary reuse guide](RESEARCHER_SUMMARY_REUSE_GUIDE.md) and [metadata QA checklist](METADATA_QA_CHECKLIST.md).
- Submit a source-backed correction using the [metadata correction contribution guide](METADATA_CORRECTION_CONTRIBUTION_GUIDE.md).

## Evidence boundaries

The library contains six preprints and one report. Protocols describe planned work; they do not report completed outcomes. The PINNACLE-VAL OSF registration is retrospective because some planned analyses had already run. Planned sample sizes are not achieved samples. The AbilityScore monograph presents preliminary operational evidence, and no completed concurrent-validity result is published. Repository resources improve discovery, reuse and auditability; they do not increase the study count or establish independent citation, indexing, peer review or endorsement.
