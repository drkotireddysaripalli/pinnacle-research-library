# Citation and version guide

## Choosing the record

- Use each Zenodo DOI as the canonical citation for the corresponding portfolio work.
- For the RCI analysis, cite Zenodo v2.0 when using the corrected reproducibility package. Cite Research Square v1 only when referring specifically to that earlier manifestation.
- Add the OSF DOI beside PINNACLE-VAL only when discussing registration or provenance. The OSF record is retrospective and is not a second study.
- Use the exact deposited author order. Do not convert the PGAF editor or research-group contributor into authors.

## Describing status

- Six canonical records are repository preprints; PGAF is a report.
- PINNACLE-VAL, PINNACLE-TRAJ and the participation review are protocols rather than completed-results papers.
- The AbilityScore monograph reports preliminary operational evidence. It does not report a completed formal concurrent-validity analysis.
- Public availability, profile inclusion and search indexing do not establish peer review, independent citation or endorsement.

## Machine-readable sources

- `CANONICAL_CITATIONS_CSL.json` — citation metadata for all seven canonical records.
- `CANONICAL_WORK_STATUS_MATRIX.csv` — per-work evidence and results status.
- `CANONICAL_DOI_RESOLUTION_MANIFEST.csv` — DOI destinations and version relationships.
- `AUTHOR_CONTRIBUTOR_ROLE_MAP.csv` — deposited order, affiliation and contributor roles.
- `CANONICAL_WORK_RELATIONSHIP_MAP.csv` — explicit work/version/registration edges.

When a title, byline, date or version differs across services, report the destination-specific value and reconcile it against the canonical repository record rather than silently overwriting either source.
