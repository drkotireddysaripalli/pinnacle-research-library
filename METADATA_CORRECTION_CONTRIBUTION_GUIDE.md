# Metadata correction and contribution guide

This public library accepts evidence-led corrections to identity, authorship, dates, work type, version relationships, status qualifiers and reproducibility resources.

## A useful correction report includes

1. The exact file and record identifier.
2. The current value and proposed value.
3. A canonical DOI, repository record or original document supporting the change.
4. The affected identity, version or evidence-state boundary.
5. The date and public URL used for verification.

## Review rules

- Preserve deposited creator order and contributor roles.
- Keep Koti Reddy Saripalli and Sreeja Reddy Saripalli distinct; do not claim namesakes.
- Treat Research Square RCI v1 and Zenodo RCI v2 as versions of one study.
- Keep PINNACLE-VAL's OSF registration retrospective and planned n=300/60 targets distinct from achieved samples.
- Keep protocols, preprints, the PGAF report and preliminary operational evidence accurately labelled.
- Do not add private participant data, unsupported qualifications, memberships, citations, endorsements or results.
- Verify the saved repository state and anonymous public state separately.

## Submission route

Use the repository's established issue or pull-request route when available, or the affected platform's official correction/support channel. Include a receipt for submitted platform corrections. Do not expose credentials, OTPs or private participant information.
